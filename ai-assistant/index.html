01 / MODEL

How it works

A multinomial Naive Bayes classifier is trained in your browser on a small, curated set of labeled issue descriptions. No external model service is called.

02 / INTERPRETATION

Not a diagnosis

Results are recommendations for initial triage only. The displayed ranking is relative model evidence, not a measured probability or guarantee.

03 / PRIVACY

Local by design

Descriptions stay in this browser session. This demo does not send them to a server or save them to an account.
